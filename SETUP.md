# Setup

1. Open https://github.com/nnthach/nnthach
2. Extract this archive. Upload README.md and the assets folder to the root of the main branch using Add file > Upload files. Keep the assets folder name.
3. Commit the files, then open https://github.com/nnthach

The profile includes custom SVG artwork and live public repository and follower badges. External cards may load slowly or become unavailable. No GitHub Actions, token or secret is needed.

Review the technology list and remove anything you do not want to represent as part of your ecosystem. Add your verified contact links in the Connect section.
